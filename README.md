# Chuanguo Xiong — academic homepage

Personal academic website: https://xiongchuanguo.github.io/

Plain HTML, CSS, and JavaScript. All website files are stored in the repository root.

- index.html: biography, research, publications, education, and contact links.
- styles.css: Arial typography and responsive layout.
- Chuanguo_Xiong_CV.pdf: public academic CV without telephone number or private identifiers.
- dic-system.png: research figure.
- favicon.svg: website icon.

GitHub Pages publishes the main branch from / (root). No installation or build step is needed.
